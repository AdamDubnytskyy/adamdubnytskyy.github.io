# AdamDubnytskyy.github.io

Personal site: Astro, deployed to GitHub Pages with GitHub Actions.

- Content lives in `src/data/site.ts` (packages, expertise, writing, contact).
- Styling is in `src/styles.css`.
- Run locally: `npm install && npm run dev`.

## Deploy
Repo **Settings → Pages → Source: GitHub Actions**. Every push to `main` deploys.
